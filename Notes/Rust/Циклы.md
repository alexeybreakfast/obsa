В `rust` есть 3 вида циклов, а именно

### loop
Является просто бесконечным циклом, делается что-то типо такого
``` rust
loop {
	do smt interesting
}
```

### while
Стандартный цикл с условием, что ещё сказать-то, что-то типо
``` rust
while a > b {
	bubub bebebe
}
```

### for
Самый кайф, в отличии от гошки тут оч приятные, почти как в питоне
``` rust
for x in (0..100) {
	println!(x)
}
```
