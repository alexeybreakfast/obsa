В `rust` есть возможность создавать функции, методы и типы, которые могут принимать несколько типов данных, например
``` rust
enum Test<T> {
	Yes(T),
	No
}
```
Может принимать вместо `T` любой тип данных, который захочется, по такому принципу работает [[Типы данных#Option|Option]], он может принимать любой тип данных, но если попробовать сделать что-то вроде такого:
``` rust
enum Test<T> {
	Yes(T, T),
	No,
}

let x: Test = Test::Yes(10, 0.1);
```
То выдаст ошибку, потому что `T` это один тип данных, а пытаемся передать ему 2 разных
Поэтому надо писать что-то такое, если ожидаются разные типы данных
``` rust
enum Test<T, N> {
	Yes(T, N),
	No,
}
```
И тогда ошибки не будет, потому что теперь `N` и `T` могут быть разными типами

## В определении перечислений, структур
``` rust
enum Test<T> {
	smt(T),
	Nope,
}
```
То же самое, но со словом `struct` в структурах

## В определении методов
``` rust
impl<T> Test<T> {
	fn....
}
```

## В определении функций
``` rust
fn test<T>(smt: T) -> AnotherSmt {
	.....
}
```
