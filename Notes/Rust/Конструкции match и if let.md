
## match
---
Конструкция match позволяет сопоставлять значение функции с некоторыми шаблонами, например:
``` rust
match x {
	0 => println!("haha"),
	1 => {
		println!("okaay");
		println!("tututu");
	},
}
```
Наполнение состоит из шаблона (левая часть) и части кода (правая часть)

Шаблоном могут быть не только значения, но и типы данных

## if let
---
Эта конструкция позволяет сравнить переменную с одним шаблоном и выглядит это примерно так:
``` rust
let conf_max = Some(21);
if let Some(max) = conf_max {
	println!("maximum is configured for {max}");
}
```
Этот код сравнит переменную `conf_max` с шаблоном `Some(max)`, и, подставив вместо `max` число 21 выведет его на экран
