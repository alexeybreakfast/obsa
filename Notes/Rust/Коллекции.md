## HashMap
Этот тип данных является аналогом словарей в питоне, чтобы получить его в rust нужно сначала добавить его из стандартной библиотеки:
``` rust
use std::collections::HashMap;
let mut map = HashMap::new();
map.insert(key, value);

for (key, value) in &map {
	println!("{key}: {value}");
}
```
Одна из особенностей HashMap в том, что там нет чёткого порядка, как в [[Типы данных#Массивы|массивах]]/[[Типы данных#Вектора|векторах]], получение данных тут происходит по ключу через метод `.get(key)`, возвращающий тип [[Типы данных#Option|Option]]
