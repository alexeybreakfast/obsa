## HashMap
Этот тип данных является аналогом словарей в питоне, чтобы получить его в rust нужно сначала добавить его из стандартной библиотеки:
``` rust
use std::collections::HashMap;
let mut map: HashMap<K,V> = HashMap::new();
map.insert(key, value);

for (key, value) in &map {
	println!("{key}: {value}");
}
```
>Где `K` — тип ключа, а `V` — тип значения

Одна из особенностей HashMap в том, что там нет чёткого порядка, как в [[Notes/Rust/Типы данных#Массивы|массивах]]/[[Notes/Rust/Типы данных#Вектора|векторах]], получение данных тут происходит по ключу через метод `.get(key)`, возвращающий тип [[Notes/Rust/Типы данных#Option|Option]]
