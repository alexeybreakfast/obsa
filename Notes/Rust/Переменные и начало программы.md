
## Начало программы

Точкой входа любой программы является функция main объявляющаяся как 
``` rust
fn main() { <код> }
```

## Объявление переменных
---
Для объявления переменных используется конструкция  `let name: type = value` но такая переменная будет не изменяемой (в rust все переменные по умолчанию являются не изменяемыми).

Для того, чтобы сделать переменную изменяемой требуется добавить пометку `mut` перед именем переменной: `let mut name: type = value`.

Так же раст может и сам определять тип переменной, так что не обязательно всегда явно указывать тип переменой: `let name = value`

Про типы данных и их значения дальше читай [[Типы данных|тут]]

## Затенение переменных
---
В rust можно объявлять переменные с именами, переменные под которыми уже объявлены, и им можно давать даже другие типы данных, например
``` rust
let x: String = "Hello!"
let x = len(x)
```
и вот, мы переменную строки превратили в числовую, такое называется ***затенением***
