## Форматоры
---
При выводе текста так же можно вставлять переменные, но важно понимать, как это делать например такой код:
	`let x = 10;`
	`println!(x);`
 выдаст ошибку при компиляции, потому что команда `println!` ожидает текст на вход, а получает переменную, тут в дело и вступают форматоры.
 
 Чтобы вставить числовую/текстовую переменную в вывод достаточно просто такой конструкции: `println!("{x}")`, если же надо вставить какое-то выражение с переменно, то можно использовать такую конструкцию: `println!("{}", x+1)`.

Для разных целей используются разные форматоры: 
- Для вывода списков, векторов, срезов и структур => форматор `{:?}` или для красивого вывода `{:#?}`
- Для автоматического перевода в некоторые системы исчисления:
	- `{:b}` — для двоичной
	- `{:o}` — для восьмеричной
	- `{:x}`/`{:X}` — для шестнадцетиричной (нижний/верхний регистр)
- Для округления `{:.N}` для округления float типов до N знаков после запятой
- Для выравнивания:
	- `{:^width}` — по центру
	- `{:>width}` — вправо
	- `{:<width}` — влево 
	> 	где width это ширина выравнивания
- Для "заполнения" строки символами и выравнивания нужного текста:
	- `{:symbol^width}` — по центру
	- `{:symbol>width}` — вправо
	- `{:symbol<width}` — влево
	>	где symbol это символ для заполнения, а width это ширина заполнения
