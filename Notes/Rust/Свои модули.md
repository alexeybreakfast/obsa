В `rust` ты можешь делать свои модули, с помощью объявления их в `src/main.rs` и дальнейшего прописывания в других файлах в `src/` например:

`src/main.rs` 
``` rust
mod test;

fn main() {
	test::ok(String::from("hello"));
}
```
`src/test.rs`
``` rust
pub fn ok(s: String) {
	println!("{s}")
}
```


или же прямо в `src/main.rs`
``` rust
mod test {
	pub fn ok(s: String) {
		println!("{s}")
	}
}

fn main() {
	test::ok(String::from("hii"))
}
```
