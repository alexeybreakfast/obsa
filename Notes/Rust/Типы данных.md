
## Числовые
Числовые типы данных делятся на __целочисленные__ и __числа с плавающей точкой__

Любой числовой тип может быть с пометкой `mut` или без неё.
### Целочисленные
Целочисленные типы данных делятся в свою очередь на числа со знаком и без.

#### Числа со знаком
Числа со знаком это `int`, их есть несколько видов, и отличаются они количеством памяти, выделенной для этой переменной. Обозначаются как `iN`, где N является $2^{n}$, где n от 3 до 7 (как раз таки число бит).
В переменные такого типа вмещается диапазон от -($2^{n-1}$) до $2^{n-1}$-1

#### Числа без знака
Числа без знака это `uint`,  в остальном тоже самое, за исключением того, что они обозначаются как `uN` и вмещают в себя от 0 до $2^n$-1

---

| Длина   | со знаком | без знака |
| ------- | --------- | --------- |
| 8 бит   | i8        | u8        |
| 16 бит  | i16       | u16       |
| 32 бит  | i32       | u32       |
| 64 бит  | i64       | u64       |
| 128 бит | i128      | u128      |

---

### Числа с плавающей точкой
Числа с плавающей точкой являются типом float и записывается как 
``` rust
let x: fN = 123.456fN
```
> Где N = $2^{n}$, где n — число 5 или 6 (как раз таки число бит)

В float помещается огромный диапазон, вам точно хватит

## Строчные
Помимо стандартного `String` типа тут есть ещё и строчные литералы `&str` являющиеся неизменяемым типом данных, и задающиеся как
``` rust
let x = "smt" 
```
Строчные литералы являются ссылками на определённые части строк, или так называемыми срезами, потому что если мы берем срез строки, то получаем ссылку на её часть, и конечно же мы не можем менять часть строки, не меняя всю остальную строку, именно поэтому `&str` является неизменяемым типом данных

В свою очередь стандартные String можно задать как
``` rust
let x = "smt".to_string()
```
Или же
``` rust
let x = String::from("smt")
```

Тип String может быть с пометкой `mut` или без неё.

Как работают срезы строк описал [[Срезы строк, массивов и векторов#Срезы строк|тут]]

## Перечисления
Они позволяют выдавать "идентификаторы" переменным и вводятся словом `enum`

``` rust
enum Test {
	first(i32),
	second(String),
	third(Vec<i32>),
}

let x = Test::first(21)
```

При выводе x  мы получим first(21), подробнее перечисления пригодятся в [[./Конструкции match и if let#match|конструкции match]].


## Структуры
Структуры тут примерно как в `go`, объявляются через
``` rust
struct Name {
	x: type,
	y: Type,
}
```

## Массивы, вектора и кортежи
### Массивы

Массив это упорядоченный список данных одного типа и фиксированной длинны задаётся вот так:
``` rust
let x: [type; len] = [.........]
```
>Где `type` — тип данных в массиве, а `len` — длинна массива

Массив может быть с пометкой `mut` или без неё, но изменяются только его элементы

Получения элемента по индексу тут работает так же как и в питоне, ничего нового, а вот [[Срезы строк, массивов и векторов#Срезы массивов|срезы]] немного отличаются.

### Вектора

Вектор это тот же массив, но без фиксированной длинны, из-за чего работа с ними медленнее, чем с массивами.
Задаются он следующим образом:
``` rust
let x: Vec<type> = vec![....]
```
>Где `type` — тип элементов вектора.

Вектора могут быть с пометкой `mut` или без неё.

Чтобы добавить элемент в вектор используется метод `ve.push(value)`
> где `ve` — вектор, `value` — значение которое хочешь добавить в вектор

Получение элемента по индексу работает либо как в питоне либо через метод `.get(index)`, возвращающий [[#Option|Option<type>]]. Как работают срезы описал [[Срезы строк, массивов и векторов#Срезы векторов|тут]].

### Кортежи

Кортеж это массив с возможностью комбинировать различные типы данных, но с заранее обозначенными типами и длинной, например
``` rust
let cort: (i32, String, [u8, 3]) = (10, "HellO!", [1, 2, 3])
```
Кортежи могут быть с пометкой `mut` или без неё.

Получение элемента по индексу работает как `t.n`, где t — имя переменной кортежа, n — индекс элемента. Нельзя взять срез кортежа.

## Option
Option является своего рода перечислением вида
``` rust
enum Option<T> {
	Some(T),
	None
}
```
> Где T может принимать любой тип

То есть если у нас есть программа, которая возвращает `Option<T>`, то она вернёт либо `Some(T)`, либо `None`, что можно отследить через конструкцию [[Конструкции match и if let#match|match]] или [[Конструкции match и if let#if let|if let]].

Не смотря на то, что `Option` является перечислением, его "подтипы" можно проверять не указывая, что они относятся к `Option`, например эта программа выведет "Yep":
``` rust
let x = Option::Some(21);
let y = Some(21);
if x == y {
	println!("Yep")
}
```

## Result
Является тоже перечислением вида
``` rust
enum Result<T, E> {
	Ok(T),
	Err(E),
}
```
Его возвращают некоторые функции, как есть или нет ошибки, так же как и Option не требует явного указания типо `Result::...`, можно просто `Ok(smt)`
