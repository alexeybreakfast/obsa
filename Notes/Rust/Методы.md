## Метод `.copied()`
Копирует значение переменной из ссылки в новую переменной (переводит из &type в type)

## Метод `.parse()`
Позволяет переводить из строки в другой тип данных, при явном указании типа данных
``` rust
let x: u8 = String::from("21").parse().unwrap() // переведёт из "21" в 21
let y = String::from("21").parse() // выдаст ошибку
let u: i64 = String::from("42").parse() // выдаст ошибку
let z = String::from("22").parse::<i32>().unwrap() // переведёт из строки в i32
```
Всегда возвращяет [[Типы данных#Option|Option]]!! 

## Метод `.expect(smt)`
Служит для обработки [[Типы данных#Option|Option]], если он возвращает `None`, то в терминал выводиться `smt`

## Метод `.sort()`
Работает как и в питоне, есть ещё **`.sort_by(|x| functionOfX)`** который работает как `key lambda x` 

## Метод `.split(char)`
Преобразует строку в `iter` тип, разбивая строку по символу, указанному вместо `char`

Его можно собрать с помощью метода [[#Метод `.collect()`|.colletc()]] 
## Метод `.split_whitespace()`
Преобразует строку в `iter` тип, разбивая строку по пробелам, если идёт несколько пробелов подряд, то удаляет лишние

Его можно собрать с помощью метода [[#Метод `.collect()`|.colletc()]] 

## Метод `.collect()`
Преобразует тип `iter` в какую-либо из коллекций, в первую очередь я использую для преобразования в вектор, можно указывать, во что переводить, используя `.collect::<type>()`

## Метод `.map(|x| functionOfX)`
Работает как `map()` в питоне, возвращает итератор с типом, который возвращает functionOfX, можно перенаправить в `.collect()` для того, чтобы преобразовать один итератор в вектор

## Метод `.trim()`
Работает как `.strip()` в питоне, возвращает строку (или срез строки, я не помню)

## Метод `.get()`
Позволяет получать элемент или срез некоторых типов данных по индексу или итератору (`n..m`)

## Метод `.unwrap()`
"Распаковывает" типы [[Типы данных#Result|Result]] и [[Типы данных#Option|Option]], то есть если у нас `Some(v)` или `Ok(v)`, то он вернёт `v`, а если `None` или `Err(e)` то вернёт `panic!`

## Метод `.map_err(|e| functionOfE)`
Работает примерно как `try except` в питоне, если происходит ошибка берет её, и делает что-то
