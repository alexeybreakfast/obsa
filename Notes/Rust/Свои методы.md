При помощи конструкции `impl` можно создавать свои методы для определённых типов данных
``` rust
struct Type {
	w: i32,
	h: i32;
}
impl Type {
	fn test(self) {
		 return self.w * self.h
	};
}
```
Тут мы объявили метод `.test()` для типа данных `Type` 

Так же можно делать метод, который принимает несколько параметров, например вот метод `.test(String)` для того же `Type`
``` rust
impl Type {
	fn test(self, s: String) {
		println!("{s}");
		return self.w * self.h
	};
}
```
