функции объявляются через
`type name(type1 name1, ....) {...};`
>Где `type` - тип переменной которую возвращает функция, `name` - имя функции, `type1` - тип параметра в функции, `name1` - имя параметра в функции

если вы хотите, чтобы функция ничего не возвращала, то используйте `void` как тип возвращаемой переменной

чтобы функция возвращала несколько типов данных (или просто несколько переменных) лучше использовать структуры, или передавать через ссылки на переменные:
``` cpp
void user(int&, std::string& name) {
	name = "susan";
	Id = 121;
};

int main() {
	int Id;
	std::string name;
	
	user(Id, name);
}
```
