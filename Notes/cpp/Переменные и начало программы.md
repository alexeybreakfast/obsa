Точкой входа в программу является функция с именем main, традиционно она возвращает код ответа программы (код ошибки), возвращение 0 означает успешное завершение программы
``` c++
int main(int argc, char* argv[]) {}
```
где `argc` - число аргументов командной строки, а `argv[]` - список аргументов, начинающийся с имени программы и заканчивающийся `nullptr` (аналог Null)
