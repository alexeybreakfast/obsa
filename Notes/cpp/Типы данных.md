## Целочисленные

| Название  | Длинна(байт) |
| --------- | ------------ |
| char      | 1            |
| short     | 2            |
| int       | 3            |
| long      | 4-8          |
| long long | 8+           |
>char так же может принимать символьные литералы через одинарные ковычки

Переменные можно делать беззнаковыми через приставку `unsigned`

## Не целочисленные
Есть 2 не целочисленных типа данных:
`float` - 32 битное число с плавающей точкой
`double` - 64 битное число с плавающей точкой

## Строчные
`char*` используется как строка, но по факту ссылка на начало строки, если используется как строка, то интерпретируется как `char[]`(массив букв, оканчивающийся на `\0`)

Так же есть тип `string` доступный из `std` или библиотеки `string`
Строки можно складывать, изменять:
``` cpp
std::string MyString = "hello";
std::string OtherString = " world";

std::cout << MyString + OtherString; // => hello world
MyString.append(OtherString); // теперь MyString содержит hello world
```

## Массивы
При объявлении массива используется формат
`type name[length];`
>где `type` - тип, `name` - имя переменной, `length` - длина массива

Массивы являются изменяемыми типами данных, индексация как в питоне

`int array[20] = {0};`
Создаст массив из 20 нулей ([0, 0, 0....])

Массив может быть объявлен динамически, т.е.:
``` c++
int a;
std::cin >> a;
char* array[a]
```
создаст массив такой длинны, которую вы введёте

## Вектора
Вектор это тот же массив, но изменяемый по длинне
``` cpp
#include<vector>

vector<int> vec = {1, 2, 3};
vec.push_back(4); // работает как .append в питоне
```
