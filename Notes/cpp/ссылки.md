В `c++` кроме указателей `*` (мы их видели в [[Notes/cpp/Типы данных#Строчные|строках]]) есть так же и ссылки `&`
В отличии от раста ссылка указывается в конце:
``` cpp
std::string str = "Hii";
std::string anotherStr = "Biee";

std::string& strRef = str; // тут мы создаём ссылку на str
strRef = anotherStr; // тут мы меням не назначение strRef, а str
std::cout << str; // => Biee
```

так же можно делать неизменяемые ссылки:
```cpp
std::string str = "Hii";
std::string anotherStr = "Biee";

const std::string& anotherStrRef = str; // это неизменяемая ссылка
anotherStrRef = anotherStr; // ошибка, константная сслыка не может быть изменена
```
