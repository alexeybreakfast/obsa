## Числовые
#### byte
Восьмибитное целое число (от -128 до 127)
`byte x = 100;`
#### short
16-битное целое число (от -32768 до 32767)
`short x = 1000;`
#### int
32-битное целое число (от -2147483648 до 2147483647)
`int x = 10000;`
#### long
64-битное целое число (я не буду писать такие числа, мне лень)
`long x = 10000L;`
если не писать L на конце, то считается как int
#### float
Какое-то там нецелое число с одинарной степенью точности
`float x = 234.5f;`
если не писать f на конце, то будет считаться как double
#### double
то же, что и float только с двойной степенью точности
`double x = 123.4;`
## Булевые
Просто типо `true/false`
`boolean x = true;`
## Строчные
#### Строки
Просто строки, можно использовать вские \ символы, типо `\n`
`String x = "Это оно, вау";`
#### Char
16-битный символ unicode типо
`char x = 'A'`
как и в расте указывается в одинарных ковычках
## Массивы
массив объявляется несколькими способами:
`type [] name = new type[len];`
`type name [] = new type[len];`
`type [] name = {...};`
`type name [] = {...};`
`type name[] = new type[] {...};`
Где `type` - тип данных массива, `name` - название массива, `len` - длинна массива, `...` - элементы массива.
Индексация массива по базе с 0 до len-1
