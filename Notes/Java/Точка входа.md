У каждой java программы должен быть публичный класс совпадающий с названием файла
``` java
public class main {
	public static void main (String[] args) {
	}
}
```
Внутри этого класса должен быть метод main который и является точкой входа программы.

Во второй строчки приведённого кода `void` значит, что код ничего не возвращает
