# Начало программы

Точкой входа любой программы является функция main() объявляющаяся как `fn main() { <код> }`

## Объявление переменных

Для объявления переменных используется конструкция  `let name: type = value` но такая переменная будет не изменяемой (в rust все переменные по умолчанию являются не изменяемыми).

Для того, чтобы сделать переменную изменяемой требуется добавить ***mut*** перед именем переменной: `let mut name: type = value`.

Так же раст может и сам определять тип переменной, так что не обязательно всегда явно указывать тип переменой: `let name = value`
